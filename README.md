# 日本旅行日语闯关

一款面向 2026 年北海道与东京旅行的 79 天日语学习 PWA，包含旅行口语、广播听力、冬季交通突发应对、片假名速认、错题复习和离线旅行模式。

## 在线使用

[打开学习工具](https://gougouw09.github.io/nihongo-trip-quest/)

学习进度仅保存在当前浏览器，不会上传到服务器。首次完整加载后，核心课程、广播音频和旅行短句可离线使用。

## 主要内容

- 每日 60 分钟五关任务与 30—60 分钟自选加练
- 新千岁机场、札幌、洞爷湖、函馆与东京旅行场景
- 列车晚点、停运、代行巴士、计划停运和站台变更听力
- 浏览器日语关键词识别与录音回放自评
- 1、3、7 天间隔错题复习和旅行护照进度
- 12 月 26 日起自动切换旅行模式
